    How the prediction works

    From your form to a score, in five steps.

    1. You enter 12 inputs

      Age, gender, country, academic level, favourite platform, purpose of use, daily usage, phone unlocks, study, activity, sleep and stress.

    2. The browser validates them

      Ranges and required fields are checked before anything is sent, using the same limits as the API.

    3. A POST request goes to FastAPI

      The values are sent as JSON to /predict. The API validates them again with Pydantic.

    4. The trained model predicts

      The API builds a one-row table, applies the same preprocessing used in training, and runs the saved regression model from Mental_Health_Model.pkl.

    5. The score comes back

      The API returns prediction_mental_health_score, and this page shows it unchanged. Nothing is simulated.

    Reading the score

    The gauge assumes a 0–10 scale where higher means better mental health, which matches the common public student social media dataset. If your model was trained on a different scale, change SCORE_MAX in script.js.

    The model learns correlations in survey data. It cannot account for an individual's circumstances, and its output should never replace professional advice.
